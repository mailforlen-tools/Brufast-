# Brufast

Train (NMBS-SNCB) and metro/tram (STIB-MIVB) in Brussels as one network. Disable a line or segment and the shortest-path search reroutes via the other operator — no hand-written fallback rules.

Languages: NL · FR · EN · DE · ES (selector top right; `?lang=fr` also works).

## Files
- `index.html`, `style.css`, `app.js`, `i18n.js` — the page (static, no build step; Leaflet from cdnjs, CARTO basemap (key in `config.js`))
- `data.js` — merged network (361 stops), generated by `tools/build_data.py` from `tools/net.source.json`, with corrected station names
- `.nojekyll` — GitHub Pages serves the files as-is

## GitHub Pages
Settings → Pages → Deploy from branch → `main` / root.

## Data
STIB-MIVB / NMBS-SNCB Open Data, CC BY 4.0 via data.belgianmobility.io. Map © OpenStreetMap contributors.

## Notes
- Map tiles: CARTO basemap (`rastertiles/voyager`, dark: `dark_all`). Put the key in `config.js`; it is public in a static site, so restrict it to the Pages domain in the CARTO dashboard. Never paste the key in chats or issues.
